Камера гостя / телефона

Изображение и микрофон передаются в эту студию. Подключение начинается после нажатия кнопки и разрешения браузера.

Не подключено

На телефоне нужен HTTPS и доступность компьютера по сети. Локальный самоподписанный сертификат нужно добавить в доверенные на устройстве; некоторые браузеры всё равно блокируют камеру до установки доверенного сертификата. HTTP подходит только для localhost на самом компьютере.

В Интернете компьютер должен быть доступен извне, включая WebRTC UDP-порты. Для сложного NAT настрой STUN/TURN во вкладке «Инструменты → Сеть» студии перед включением сервера. Используются только явно заданные relay-серверы; по умолчанию список пуст. Встроенного облачного ретранслятора нет.
