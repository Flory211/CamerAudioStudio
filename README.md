##  Описание

CamerUdioStt — это приложение для создания виртуальной камеры и микрофона с применением эффектов обработки в реальном времени. Идеально подходит для стримов, видеозвонков и записи контента.

### Возможности

**📹 Видео:**
- Захват с веб-камеры, экрана или конкретного окна
- 14 видеоэффектов: яркость, контраст, насыщенность, гамма, температура, размытие, резкость, виньетка, пикселизация, сепия, ч/б, инверсия
- Настраиваемое разрешение (640×480, 1280×720, 1920×1080) и FPS (15-30)

**🎙️ Аудио:**
- Захват с микрофона или системного аудио
- Эффекты: изменение тона (pitch), громкость, реверберация
- Кнопка мута для отключения превью

**⚙️ Интерфейс:**
- Компактный дизайн в стиле cyberpunk
- Переключение режимов: Эффекты / Источник / Настройки
- Перетаскиваемое окно
- Always on top режим

## 🚀 Быстрый старт

### Установка зависимостей

**Обязательные компоненты:**

1. **Python 3.10+** — [Скачать](https://www.python.org/downloads/)

2. **OBS Studio** (для виртуальной камеры) — [Скачать](https://obsproject.com/)
   - После установки Virtual Camera работает автоматически

3. **VB-CABLE** (для виртуального микрофона) — [Скачать](https://vb-audio.com/Cable/)
   - Запустить `VBCABLE_Setup_x64.exe` от имени администратора
   - Перезагрузить компьютер

### Установка приложения

```bash
# Клонируем репозиторий
git clone https://github.com/ТВОЙ_НИК/CamerUdioStt.git
cd CamerUdioStt

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем
python main.py
```

##  Использование

### Запуск

```bash
python main.py
```

При первом запуске появится предупреждение Alpha-версии — нажми "Принимаю".

### Настройка видео

1. Открой вкладку **Видео**
2. Нажимай кнопку **⚙** для переключения режимов:
   - **Эффекты** — настрой яркость, контраст и т.д.
   - **Источник** — выбери камеру/экран/окно
   - **Настройки** — разрешение, FPS, бэкенд
3. Нажми **▶ Запустить**
4. В Zoom/Discord выбери камеру: **OBS Virtual Camera**

### Настройка аудио

1. Открой вкладку **Аудио**
2. Нажимай кнопку **⚙** для переключения режимов:
   - **Эффекты** — тон, громкость, реверб
   - **Источник** — выбери микрофон или "Стерео микшер"
   - **Вывод** — выбери **CABLE Input**
3. Нажми **▶ Запустить**
4. В Zoom/Discord выбери микрофон: **CABLE Output (VB-Audio Virtual Cable)**

### Кнопка мута 🔇

- **Нажата (красная)**: превью аудио отключено (уровень не показывается)
- **Не нажата**: уровень звука показывается
- Аудио всегда отправляется в виртуальный микрофон

## 📁 Структура проекта

```
CamerUdioStt/
├── main.py              # Точка входа
├── config.py            # Настройки по умолчанию
├── requirements.txt     # Зависимости Python

├── README.md

    ├── main_window.py   # GUI приложения
    ├── video/
    │   ├── capture.py   # Захват видео (камера, экран, окно)
    │   ├── effects.py   # 14 видеоэффектов
    │   ├── processor.py # Обработка в отдельном потоке
    │   └── output.py    # Виртуальная камера (pyvirtualcam)
    └── audio/
        ├── capture.py   # Захват аудио
        ├── effects.py   # Pitch, Gain, Reverb
        └── output.py    # Виртуальный микрофон (VB-CABLE)
```
